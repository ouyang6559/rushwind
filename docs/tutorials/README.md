# RushWind 系列教程

一套从"第一个小时"到"生产化运维"的渐进式教程。每一章都可以独立上手跑通，所有代码片段都取自仓库内已验证的源码与示例（`examples/`），不做凭空演示。

## 前置要求

- Rust 稳定版工具链（仓库带 `rust-toolchain.toml`，clone 后 rustup 会自动对齐）。
- 熟悉 Rust 的所有权与 `async/.await`；了解 tokio 的基本概念（任务、关闭信号）即可，不需要精通。
- 运行 `examples/` 不需要任何外部服务；教程中标有 **live** 的部分（第 07、09、13 章）需要对应的容器，缺了也不影响主线学习。

## 贯穿全系列的四个心智模型

1. **契约与引擎分离**。每个域（存储、消息、缓存、注册……）只有一份契约 crate，引擎是该契约的一种构造方式。业务代码面向契约，引擎选择是装配期的决定。
2. **装配期决定一切**。引擎、认证方案、中间件都是在组装时注入的；配置驱动的 `Bootstrap` 可以把整份装配写成一个 YAML 文档。
3. **错误是值**。每个域都有非穷尽的错误枚举，带稳定的状态码与错误码字符串；边界处显式拒绝不支持的能力，绝不静默吞掉。
4. **能力可以探测**。脚本引擎等可选能力通过 `as_xxx() -> Option<...>` 探针暴露；框架默认"积木盒全开"，限制是你显式装上去的。
